verification sessions. They are retained as historical evidence, not as the
current implementation guide. Use the repository's active documentation and
`WORK_PLAN.md` for current behavior and remaining work.

- [`plans/`](./plans/) contains superseded project and rebuild plans.
- [`reviews/`](./reviews/) contains code reviews and verification reports.
